# TeReL artifact provenance

The manuscript contains the method, evaluation protocol, and scientific
results. This file contains the execution identifiers and hashes needed to
audit the reported records. Runs use Python 3.12, deterministic PyTorch and
cuDNN behavior, and the cuBLAS workspace configuration recorded by each
manifest.
